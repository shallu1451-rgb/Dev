# Dev Tour and Travels - Website

Modern, responsive travel agency website for **Dev Tour and Travels**, featuring handcrafted Mumbai Tour Packages, interactive filters, day-by-day itinerary modal viewer, and instant WhatsApp booking integration.

## 🚀 Features
- **Dedicated Separate Pages for Every Tour Package**: Individual comprehensive landing pages with rich hero banners, day-by-day timeline itineraries, inclusions/exclusions checklists, stay standards, policies, and embedded direct booking forms.
- **Modern Luxury Aesthetic**: High-contrast Deep Marine Teal, Warm Amber Gold, and Slate theme.
- **Interactive Tour Packages**: Dynamic client-side filtering by duration, inclusions, hotel amenities, and live text search.
- **Itinerary & Policy Viewer**: Tabbed modal displaying day-wise schedule, inclusions/exclusions, and cancellation terms.
- **Instant Booking Enquiry**: Form validation with direct WhatsApp quotation dispatch.
- **Mumbai City Highlights**: Visual landmark cards (Gateway of India, Marine Drive, Elephanta Caves, CST, Siddhivinayak, Bollywood Film City).
- **Mobile Optimized**: Responsive design with sticky bottom action bar (Call, WhatsApp, Enquire).
